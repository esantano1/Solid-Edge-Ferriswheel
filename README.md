# Ferris Wheel

This repository contains the 3D CAD design files and corresponding technical drawings for the Ferris Wheel project

## 📂 Project Structure

The model was designed using parametric CAD software (such as Solid Edge) and consists of the following file types:

*   **`base.asm` (Main Assembly):** The central file of the project. It contains the complete Ferris wheel assembly with all linked parts and applied geometric constraints.
*   **`.par` Files (Parts):** Individual 3D models for each component of the Ferris wheel (e.g., cabins, shafts, supports, connectors).
*   **`.dft` Files (Drawings):** 2D technical drawings including dimensions, tolerances, and specifications required for manufacturing or review.

## ⚙️ Software Requirements

To view, analyze, or edit this project, you will need:
*   **Solid Edge** (recommended for full editing capability).
*   Alternatively, any CAD viewer compatible with native `.asm`, `.par`, and `.dft` file formats.

## 🚀 How to Open the Project

1. Clone this repository or download the full project as a `.zip` file using GitHub's green **Code** button.
2. If downloaded as a `.zip`, extract **all** files into a single local folder. 
   > **Note:** All files must remain in the exact same folder directory. If you move or isolate the main assembly file, the CAD software will fail to locate the part references.
3. Launch your CAD software.
4. Select "Open" and select the primary **`base.asm`** file. The software will automatically load the complete structure by referencing the associated `.par` files.
